# Measurement distributions

Volume: 79 complete matched cells with IoU >= 0.5, retained after signal filtering. Distance: 73 matched signals, comparing stored manual A–B lengths with full-pipeline distances. Histograms show counts using shared bins for manual and predicted values. Signed error is predicted minus manual; cumulative plots show the proportion within each absolute error. All observations, including outliers, are included. These are conditional distributions, not estimates of detection recall.

PNG previews, scalable SVGs and PDF copies are supplied. Rerun with `python scripts/plot_measurement_distributions.py`.
